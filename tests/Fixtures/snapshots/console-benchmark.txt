      File:          app/Http/Controllers/Vuln/AccountController.php
      Line:          14
      Symbol:        App\Http\Controllers\Vuln\AccountController::update
      Category:      Mass Assignment (CWE-915)
      Confidence:    high
      Context:       PUT /vuln/account is protected only by the web and auth middleware. UpdateAccountRequest::authorize returns true, and its rules validate only "name" and "email". The record updated is the caller's own account, loaded at L13 via $request->user()->account.
      Flaw:          L14 calls $account->update($request->all()). all() returns every input key the client sends, not just the validated name and email.       Suggested Fix: Write only the validated fields with $request->validated() or $request->only(['name', 'email']). Also replace the empty $guarded on Account with an explicit $fillable whitelist, e.g. ['name', 'email'].
